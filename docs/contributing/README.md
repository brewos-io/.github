# Contributing to BrewOS

Thank you for your interest in contributing to BrewOS!

## How to Contribute

### Code Contributions

1. **Fork the repository** you want to contribute to
2. **Create a feature branch**: `git checkout -b feature/my-feature`
3. **Make your changes** following the repository's coding standards
4. **Test your changes** thoroughly
5. **Commit with clear messages**: `git commit -m "Add feature X"`
6. **Push and create a PR**: `git push origin feature/my-feature`

### Documentation Contributions

Documentation improvements are always welcome! See each repository's documentation:
- [Firmware Docs](https://github.com/brewos-io/firmware/tree/main/docs)
- [App README](https://github.com/brewos-io/app#readme)
- [Cloud README](https://github.com/brewos-io/cloud#readme)

### Testing

Help us expand machine compatibility! See [TESTERS.md](https://github.com/brewos-io/firmware/blob/main/TESTERS.md)

## Development Priorities

| Priority    | Area         | Description                       |
| ----------- | ------------ | --------------------------------- |
| 🔴 Critical | Safety       | Any safety improvements           |
| 🟠 High     | Stability    | Bug fixes, reliability            |
| 🟡 Medium   | Features     | New machine support, integrations |
| 🟢 Normal   | Enhancements | UI improvements, optimizations    |
